_This project was originally submitted as a final assessment for the **Kreativt Webprosjekt** course at **Høyskolen Kristiania**._

Vinterland is a Norwegian winter travel website created with HTML and CSS. The website presents winter activities, destinations, accommodation options, indoor activities, and travel planning information for Telemark.

The project focuses on creative visual design, CSS animations, local image resources, and a winter-themed user experience.

---

## ✨ Features

- Winter-themed layout and visual design
- Animated snowfall effect
- Animated skier and mountain illustration
- Winter activity sections for skiing, cabin trips, and indoor activities
- Destination page with recommended locations in Telemark
- Animated image gallery
- Holiday planning form
- Contact form
- Navigation menus and internal page links
- Hover effects created with CSS

## 📂 Project Structure

```text
vinterland/
├── index.html          # Main page with activities, gallery, and forms
├── destinations.html   # Destination recommendations in Telemark
├── styles.css          # Layout, styling, animations, and hover effects
├── bilder/             # Local images used throughout the website
└── README.md           # Project documentation
```

---

## Getting Started

1. Download or clone the project.
2. Open `index.html` in a web browser.
3. Use the navigation links to explore the activities and destinations.

No build tools, packages, or dependencies are required.

---

## Local Resources

All images and other visual resources used by the website are stored locally in the `bilder/` directory. The project does not link to external images, videos, fonts, or libraries.
